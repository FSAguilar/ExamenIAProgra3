##Componentes de Jetpack Compose
Componente		Función
Scaffold		Estructura principal de la aplicación.
Column			Organiza los elementos verticalmente.
Row			Organiza información horizontalmente.
Text			Muestra nombres, precios y atributos.
LazyColumn		Lista los productos de forma eficiente.
Card			Representa visualmente cada producto.
Icon			Íconos de la aplicación y navegación.
OutlinedTextField	Permite buscar productos por nombre.
NavigationBar		Barra inferior para cambiar de pantalla.
NavigationBarItem	Opción de navegación para cada categoría.
Modifier		Configura tamaños, márgenes y espaciado.
